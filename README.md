# Homebrew

Homebrew is a web app for home cafés: small coffee setups run from someone's kitchen or garage. Customers find a café and pre-order for pickup. Café owners manage their menu, opening hours and order queue. Admins approve cafés and keep reviews honest. Each role also has an AI feature powered by SoCLaaS.

## User roles

| Role | What they do |
| --- | --- |
| **Customer** | Browse approved cafés, pre-order with a pickup slot, track and cancel orders, review collected orders |
| **Café owner** | Register a café, manage menu, prices and opening hours, run the order queue, view sales |
| **Admin** | Approve or suspend cafés, moderate reviews, approve featured-café boosts |

## Getting started

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.
